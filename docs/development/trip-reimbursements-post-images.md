# Expense provenance and post image editing

The organiser cost sheet now defaults to direct reimbursements grouped by original recorded payer and participant. Each relationship expands to its source expenses. It excludes EACH_PAYS_OWN and missing FX. It does not alter costs or assert that payment/reimbursement has occurred. The previous greedy net settlement remains in a collapsed optional group-netting section, explicitly explaining that transfers can cross unrelated expense relationships. Allocated-to-pay replaces the misleading Paid label in the member summary. Per-expense rounded shares may differ by a cent from aggregate balances; no financial records are rewritten.

The saved-cost warning now uses the same CHF-equivalent threshold as the editor (1000 CHF per person, EACH_PAYS_OWN, PER_PERSON, multiple participants), suppressing warnings when conversion is unavailable or another base currency is used. Ordinary foreign-currency green fees are not automatically flagged merely for their payment mode.

Owners can remove existing post photos and add replacements (maximum five, JPEG/PNG/WebP, five MB each). Cancel is local only. PATCH accepts JSON or multipart; retained image IDs must belong to the post. Ownership, limits, empty-post prevention, file signatures and all enabled moderation checks precede public upload. The service repeats ownership/ID validation and uses updatedAt optimistic concurrency. Image association changes are one nested database mutation; existing post ID, likes/comments remain. Uploaded replacements are cleaned if saving fails. Removed file cleanup checks other post, trip-cover, avatar and course-submission references; failed cleanup does not undo a committed post edit and is reported as mediaCleanupFailures. No blanket CDN-cache erasure guarantee is implied. A deleted PostImage selected as a course cover uses the existing FK SetNull; cover hooks refresh after image edits.

Validation includes API ownership/foreign-ID/version/count/content/moderation/cleanup cases plus real Nest HTTP multipart/JSON interceptors; browser tests cover remove/cancel/replace/reload at 390 and 1280px; accounting tests cover direct expense provenance and foreign-currency warning thresholds. Synthetic fixtures only; investigation of the reported Stage trip was read-only. No user post or trip data was modified to test this feature.
